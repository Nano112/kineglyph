# Kineglyph in one HTML file

This example uses the pinned, self-contained browser bundle from esm.sh. No package installation or
JavaScript build configuration is required.

Serve the directory with any local HTTP server, for example:

```sh
npx vite .
```

Open the URL Vite prints. See `docs/plain-html.md` for the npm-installed alternative, responsive
embedding, live data, cleanup, and static-image fallback.
